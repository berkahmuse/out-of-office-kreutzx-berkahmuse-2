One line of an out-of-office auto-reply, the funniest I could write in 140
characters or fewer, for the [make.fun bounty "The Funniest Out-of-Office"](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf).

## The line

> I'm out of office until Monday, living my best life as a houseplant: watered weekly, spoken to rarely, thriving anyway.

(119 characters, one line.)

## How it works

`main.py` is deterministic: it writes that exact line to `/output/entry.txt`
on every run. No network, no randomness, no input files.

```sh
python3 main.py
cat /output/entry.txt
```
